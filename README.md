Participant-side engine to plug into an existing project of mine 
[Valkyrie](www.github.com/Semilore317/valkyrie-dotnet).


The setup is simple, Valkyrie is an exchange that has different configurable modes...

It can work with actual participants where skoll is one of them and can test different trading strategies  
with the market and other participants(which might be other instances of skoll running).
